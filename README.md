# Site_SEO

Site da agência fictícia **KaisenStudios**, feito para um trabalho de faculdade (IFSP) sobre SEO, com HTML, CSS e um pouco de JavaScript. Os arquivos ficam todos na raiz, sem separação em pastas.

Online: https://sousax.github.io/Site_SEO/

## O que tem

- Páginas: início (`index.html`), serviços e preços (`services.html`), processos (`process.html`), login (`login-page.html`) e página do professor (`professor.html`)
- SEO on-page: `meta description` e `meta keywords` em cada página
- `sitemap.xml` (gerado para o deploy em kaisenstudios.netlify.app) e `robots.txt` bloqueando `professor.html`
- Google Analytics (gtag) em `index.html`, `services.html` e `process.html`
- `report.pdf`: relatório exportado do Google Analytics (27/05 a 23/06/2023)
- Página do professor com os dados da entrega: palavras-chave, links para sitemap, robots.txt e relatório
- Menu mobile com animação (`mobile-navbar.js`)
- Formulário de login apenas visual, sem back-end

## Tecnologias

- HTML5
- CSS3 (fonte Outfit local)
- JavaScript puro
- Google Analytics 4

## Como rodar

Clone o repositório e abra `index.html` no navegador.
